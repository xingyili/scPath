# Pathway Priors

The model reads species-specific GMT files from `human/` or `mouse/`.
The example uses the human `Reactome.gmt` and `KEGG.gmt` files. The other two
files are included for the mouse workflows archived with the project.

These files are preserved from the original project. Their inclusion does not
grant redistribution or reuse rights; consult the upstream database terms and
request permission from the rights holders as described in the project access
