# Data and Provenance

The GitHub package includes one prepared PBMC example and four pathway GMT
files. The five full study archives are provided separately as restricted
Zenodo files, organized as one archive per study plus one shared original-core
archive. Each archive contains source notebooks, selected inputs and historical
outputs; files retain original content and are not recomputed by this release.

## Study lineages

| Study | Original processing and experiment code | Input to experiment | Output retained in archive |
| --- | --- | --- | --- |
| Cross-platform PBMC | `data/RNA/6_PBMC/data_solve*.ipynb`, `data_for_PML.ipynb`; `benchmark/cross_platform(small)/batch_batch/platform copy.ipynb` (72-pair runner) and `platform.ipynb` (single-pair analysis) | Prepared `experiments/<pair>/{train,test}` folders under `benchmark/cross_platform(small)/batch_batch/` | Selected per-pair prediction AnnData files and metric tables |
| Cross-tissue atlas | `benchmark/cross_tissue/experiment/exp4_findnew/exp4_findnew.ipynb` and `exp4_final.ipynb` | Tabula Muris 10x and Smart-seq combined AnnData objects generated by `exp4_findnew.ipynb` | Selected experiment AnnData files and comparison metrics |
| Cross-disease pancreas | `benchmark/cross_disease_states/mouse_pancreas/data_solve.ipynb`; `benchmark/cross_disease_states/exp/train_mouse_pancreas.ipynb` | Disease-split inputs derived from `data/mouse_pancreas_cross_disstate.h5ad` | Selected prediction AnnData files and result tables |
| Bone-marrow aging | `benchmark/cross_time/exp_TMS/train_bone_marrow.ipynb` | The project's local Tabula Muris Senis AnnData input, split into the 20-month-and-older reference and query data | Selected prediction AnnData files and analysis tables |
| PDAC/NACT | `benchmark/NACT/exp1_t2.ipynb`, `exp2_all.ipynb`, and downstream analysis notebooks | Clinical PDAC inputs and processed AnnData files under `benchmark/NACT/` | Selected historical prediction files and summary tables |

The experiment archives use files selected from the original directories,
not new downloads or regenerated matrices. Their per-file manifests map each
archive member to the original path. Large model checkpoints, regenerable
graphs, redundant trial outputs, and raw sequencing reads are omitted unless
listed in that archive's manifest. The cross-platform 72-pair workflow and
the included one-pair CEL-Seq2 example use different notebook entry points;
the example should not be interpreted as a rerun of all 72 pairs.

## Included example

`data/RNA/cel_seq2/` is the prepared CEL-Seq2 reference and 10x Chromium V2
query pair already used in the original PBMC benchmark. The eight data files
were copied from the prepared pair; the matching original pair was verified to
have identical file contents. `data/pathway/{human,mouse}/` contains the four
pathway GMT files from the source project.

For full upstream dataset provenance, see the per-study `DATA_SOURCE.md` files
inside the restricted experiment archives and the original source notebooks.
Those notes identify source directories and the intermediate prepared files;
they do not claim that raw FASTQ or complete parent atlas downloads are
included.
