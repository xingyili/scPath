# Access and Publishing

## GitHub

The code repository is private. A GitHub private repository has no public
self-service access-request button; the owner must invite approved GitHub
accounts as collaborators. Do not put credentials, unpublished clinical
records, or local token files in the repository.

## Zenodo

The Zenodo record metadata and DOI are public. The associated files are
restricted. Interested users can use Zenodo's request-access flow; the record
owner reviews requests individually. Approval provides file access only and
does not grant permission to redistribute, modify, or otherwise reuse the
materials. Further use requires written permission from the rights holders.

The software and research data are designated “Other (Not Open)” / all rights
reserved. The original terms of upstream datasets and third-party resources
continue to apply. Contact the corresponding authors listed in the manuscript
for access requests. The Zenodo record will be referenced here after formal
publication.

Zenodo permits post-publication metadata corrections. Substantive file changes
should be released as a new version so the cited record remains stable; a new
version receives its own version-specific identifier and preserves the previous
version. See [Zenodo record management](https://help.zenodo.org/docs/deposit/manage-records/),
[file management](https://help.zenodo.org/docs/deposit/manage-files/), and
[version management](https://help.zenodo.org/docs/deposit/manage-versions/).
